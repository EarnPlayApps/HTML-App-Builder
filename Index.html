Publish Guide: HTML App Builder membantu menyediakan projek dan konfigurasi. Proses akhir bina APK/AAB atau IPA serta penghantaran ke store perlu dibuat menggunakan tool/platform pembangunan yang sesuai.

🤖 Google Play

  1. Pastikan nama app dan package ID betul.
  2. Pastikan versi app telah dinaikkan jika membuat release baru.
  3. Gunakan projek Android yang telah dibina.
  4. Build release AAB.
  5. Semak polisi kandungan dan polisi iklan.
  6. Daftarkan aplikasi di Google Play Console.
  7. Upload AAB dan lengkapkan maklumat store.

🍎 App Store

  1. Gunakan projek iOS yang telah dibina.
  2. Pastikan Bundle ID sepadan.
  3. Semak konfigurasi AdMob untuk iOS.
  4. Build menggunakan tool pembangunan iOS.
  5. Uji aplikasi pada peranti.
  6. Gunakan App Store Connect untuk submission.
  7. Lengkapkan metadata dan privacy information.
